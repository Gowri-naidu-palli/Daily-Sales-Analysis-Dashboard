# Daily Sales Analysis Dashboard

This project is a sales dashboard developed using Python, Streamlit, and Plotly to analyze sales data and display important business insights through interactive charts and visualizations.

## Features
- View sales data in an interactive dashboard
- Analyze sales and profit information
- Visualize data using charts and graphs
- Filter and explore sales records easily

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## Files Included
- app.py
- requirements.txt
- sales_data.csv
- Global Superstore.xls

## How to Run
1. Install the required libraries:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   streamlit run app.py
   ```
